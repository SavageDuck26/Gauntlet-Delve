# data/ — inputs and vocabularies

`vocab/` holds the word lists the GPU pattern sweeps read. Everything here is
regenerated by the `tools/make_*_vocab.py` builders, so deleting a file only
costs a re-run.

## Targets (written by `tools/build_targets.py`)

| file | contents |
| --- | --- |
| `targets_<type>.txt` | unresolved hashes for one resource type (`texture`, `material`, `animation`, `unit`, `level`, `particles`, `shader_library`, …) |
| `unresolved_targets.txt` | the union of all of them |

## Current vocabularies (per family)

| family | files | shape |
| --- | --- | --- |
| texture / material | `tex_dir.txt`, `tex_leaf.txt`, `tex_suf.txt`, `tex_root.txt` | `%d/%l%s` |
| level (quilts) | `lvl_env.txt`, `lvl_sub.txt`, `lvl_shape.txt`, `lvl_edge.txt`, `lvl_nn.txt`, `lvl_nn_hi.txt`, `lvl_mod.txt` | `modules/d01_%a/%b/%a_quilt_%s__%e__%n[_%m]` |
| particles | `par_dir.txt`, `par_pre.txt`, `par_sub.txt`, `par_verb.txt`, `par_mod.txt` | `%d/%p_%s_%v[_%m]` |
| units / blocks | `unit_*.txt` (grammar) and `ub_*.txt` (mined: root/env/cat/style/part/orient/width/var/char/gib) | `%r/%e/%c/%s_%p…` |
| animation | `anim_map.json` (unit → clip hashes, from the state machines), `anim_targets.txt`, `*_tok.txt`, `animation_parents.txt` | edit-distance-1 per unit |
| live scratch | `known.txt`, `events.txt`, `bundle_words.txt`, … | supporting lists |

## Legacy vocabularies

`big_dict.txt`, `big2_dict.txt`, `medium_dict.txt`, `small_dict.txt`,
`classes.txt`, `creatures.txt`, `loc_*`, `fx_*`, `ma_*`, `flow_*`, `clip_*` and
friends were built by the cartesian sweeps now in `legacy/`. They are kept
because the wide unit/tex sweeps still fold in some of their tokens, but nothing
in `tools/` or `generators/` regenerates them.
